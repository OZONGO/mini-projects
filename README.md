# mini-projects

2027 春招 AI 应用开发方向的学习作品集：阶段一（Python 基础）的四个迷你项目，同一仓库下各占一个子目录。

> 起草：AI ｜ 内容确认：OZONGO

## 项目索引

| # | 目录 | 项目 | 主要学到 | 计划周次 | 状态 |
|---|---|---|---|---|---|
| MP1 | `mp1-weekly-report/` | 学习周报生成器 | 文件读写、字符串处理、函数与 OOP、argparse | W3-W4 | v0.1 进行中（parse 段） |
| MP2 | `mp2-file-organizer/`（待建） | 文件整理工具 | os/pathlib/shutil、递归、防御式编程、日志 | W5 | 未开始 |
| MP3 | `mp3-jd-matcher/`（待建） | 简历 JD 匹配器 | 函数设计、jieba 分词、评分逻辑、测试 | W6 | 未开始 |
| MP4 | `mp4-deepseek-cli/`（待建） | DeepSeek API CLI 助手 | requests、JSON、API、流式、重试、配置管理 | W8 | 未开始 |

每个项目的交付标准：README（做什么/怎么用/设计说明）＋至少 3 个测试＋干净的提交历史。

## 数据来源

MP1 的输入是学习记录仓库 `learning-log` 里的会话日志 `sessions.md`
（本目录位于 `L/mini-projects/`，故相对路径为 `../../learning-log/sessions.md`）。
